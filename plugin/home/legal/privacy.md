# HOME Privacy Policy

_Last updated: 25 September 2026_

HOME is a personal productivity and learning service that can be used through ChatGPT/Codex and, separately, through HOME clients.

## Controller

Before public release, replace this section with the verified publisher's legal name, postal address, privacy contact email, and any other information required in the launch jurisdictions.

## Data HOME processes

For the public HOME plugin, HOME may process:

- account identifiers supplied through the HOME authentication provider;
- tasks, notes, task status, due times, areas, and priorities that the user chooses to store;
- learning cards, reflections, feedback, and optional learning scores that the user chooses to store;
- profile settings needed to provide the service, such as timezone preferences;
- minimal technical logs needed for security, reliability, abuse prevention, and debugging.

HOME does not require precise device location, contacts, SMS, WhatsApp content, Android Accessibility data, or notification scraping for the public plugin.

## How the data is used

HOME uses stored data to provide the actions the user requests, such as listing tasks, creating or updating a task, planning from the user's stored information, and saving learning progress. ChatGPT/Codex provides the conversational reasoning layer and may send the information required for a selected HOME tool call to HOME's MCP server.

HOME does not sell personal data.

## Service providers

The public plugin is designed to use Supabase for authentication, database storage, Row Level Security, and serverless MCP hosting. ChatGPT/Codex is operated by OpenAI and remains subject to the user's applicable OpenAI terms and privacy controls. Before release, this section must be updated with the exact production subprocessors, regions, contracts, and international transfer mechanisms actually used.

## Retention

HOME data should be retained only for as long as needed to provide the service or meet applicable legal obligations. The production policy must state concrete retention periods for account data, application data, backups, security logs, and deletion requests before launch.

## User controls

Users can disconnect the HOME plugin from ChatGPT/Codex at any time. HOME will provide a production process for requesting access, correction, export, and deletion of stored HOME data. Before publication, add the final HTTPS deletion/support URL and monitored privacy contact here.

## Security

HOME uses authenticated access and per-user database policies designed to prevent one user from accessing another user's data. Production systems should use encrypted transport, asymmetric signing keys, least-privilege credentials, secret management, rate limits, dependency updates, and security monitoring.

## Children

The public HOME plugin is not intended to knowingly collect personal data from children where parental consent or other special authorization would be required by applicable law.

## Changes

Material changes to this policy will be reflected by updating the date above and, where required, notifying users through the service.
