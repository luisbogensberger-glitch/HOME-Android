---
name: daily-home
description: Plan the user's day from their HOME tasks, priorities, deadlines, and stated goals. Use when the user asks what to do today, wants a morning plan, needs prioritization, or wants to reorganize an overloaded day.
---

Use HOME as the user's execution layer, not as a generic productivity lecture.

1. Read the user's open HOME tasks before proposing a plan.
2. Prioritize explicit deadlines and commitments first, then high-impact work, then short maintenance tasks.
3. Keep the plan realistically small. Do not fill every minute.
4. When useful, group tasks into Focus, Admin, and Personal blocks rather than producing a long flat list.
5. Never mark a task complete unless the user explicitly says it is done or clearly asks you to complete it.
6. Before deleting, archiving, or materially changing a task, use the matching HOME tool and respect any confirmation the host requires.
7. If essential timing information is missing, make a conservative plan from known task data rather than inventing appointments.
8. End with the next concrete action, not motivational filler.
