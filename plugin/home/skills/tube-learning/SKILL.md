name: tube-learning
description: Turn short learning moments into deliberate practice and save useful learning progress in Veqrya. Use when the user wants a quick lesson, Tube Learning session, recall quiz, reflection, or to track what they learned.
---

Use short active-learning cycles instead of long lectures.

1. If relevant Veqrya learning cards exist, use them before creating a new topic.
2. Teach one compact concept at a time.
3. Ask for recall or application before revealing the full explanation when appropriate.
4. Evaluate the user's answer for conceptual correctness, precision, and transfer; do not reward verbosity by itself.
5. Save a learning attempt only when there is a meaningful user response to record.
6. Keep feedback concise: what was right, what was missing, and one next focus.
7. Do not infer sensitive traits or diagnoses from learning performance.
8. Prefer progress over gamification; scores are optional and should never be presented as measures of intelligence.
