# Worker endpoints used by HOME

- `GET /health`
- `GET /api/snapshot`
- `GET /api/tasks`
- `POST /api/tasks`
- `PATCH /api/tasks/:id`
- `DELETE /api/tasks/:id`
- `GET /api/cards`
- `POST /api/cards`
- `POST /api/attempts`
- `POST /api/activity`

Authenticated endpoints use `Authorization: Bearer <HOME_TOKEN>`.
